McCarthy, Reference, and XCON

Week 1 homework · Question 3: Presuppositions as design commitments, not metaphysics.

On page 8 of the essay, McCarthy explains the correspondence theory of reference using a robot that was asked to pick up a block labelled "B3". The robot needs to pick up that exact block and no other similar looking blocks with a different label. If it picks up a different one, it has not followed the instruction, even if it successfully grabbed something. The point is that the name B3 in the robot’s system has to match the object it is supposed to identify. But having a label is not enough if the robot connects it to the wrong thing.

An engineer that develops a robot would need to make that connection work and test it effectively. For example, they could put several blocks in front of the robot and ask it to pick up B3. If it chooses the wrong one, they would need to figure out whether it confused the labels, failed to recognize the block, or moved toward the wrong object. This makes McCarthy’s overall idea a practical design requirement. The engineer does not need to answer every single philosophical question about how symbols get their meaning, instead, they need to build a robot that can use a symbol to identify and pick up the correct object.

This idea connects to XCON, which we covered on slide 22 of the history lecture. XCON was an expert system used to configure computer orders for Digital Equipment Corporation. McCarthy’s idea would matter a lot here because the component names in a configuration would need to identify the exact computer parts. Suppose the system followed its rules but one of its component names referred to the wrong part, the resulting order could still be incorrect. This related to the robot picking up the wrong block. In both cases, the system’s information needs to match the things it is working with for it to complete the task correctly and effectively.

  • John McCarthy, The Philosophy of AI and the AI of Philosophy, Section 3.
