HISTORY · ENTRY 01

From Expert Systems to the AI I Use Today

One part of AI history that stood out to me was XCON, an expert system used by Digital Equipment Corporation to configure computer orders. It used rules provided by human experts to solve a specific problem. In my Week 1 homework, I connected this to McCarthy’s example of a robot being asked to pick up a block called B3. The robot needs to connect that name to the correct block. I applied the same idea to XCON: even if it followed its rules, the order could still be wrong if its information referred to the wrong computer part.

The lecture also showed how AI moved toward systems that learn patterns from data instead of relying mainly on rules written by experts. Today’s AI coding tools use those learned patterns to generate code for many different requests. What I learned is that AI has not always worked like the tools I use now. Systems like XCON focused on a narrow task, while modern tools can handle a wider range of tasks. However, being more flexible does not mean they always understand or follow a request correctly.

I experienced this when I asked an AI tool to change one thing in my app, and it changed other parts of the code too. I had to go through the code and fix those changes. Knowing how to code helped me notice what went wrong. This was not necessarily the same kind of error that XCON could make, but it reminded me that producing an output and completing the right task are different things. Connecting the history to my own experience helped me see why I should understand how an AI tool works and check its results, rather than assume that newer technology is always reliable.
